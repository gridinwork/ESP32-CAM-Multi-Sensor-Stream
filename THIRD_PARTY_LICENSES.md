# Third-party components

This repository's original firmware and documentation are licensed separately under the MIT License.

The firmware depends on third-party software that remains under its respective upstream licenses:

- **Arduino-ESP32 / ESP32 camera support** — Espressif Systems. Check the license in the installed Arduino-ESP32 package.
- **Adafruit MPU6050** — Adafruit Industries. See the upstream library repository for its license.
- **Adafruit Unified Sensor** — Adafruit Industries. See the upstream library repository for its license.
- **VL53L0X Arduino library** — Pololu. See the upstream library repository for its license.
- **pyserial** — used only by the optional Python receiver example; see the pyserial project for its license.

No third-party library source code is vendored in this repository.
